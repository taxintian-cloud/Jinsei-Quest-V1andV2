      人生クエストの遊び方

      1. 冒険者名を入力してログイン
        データが保存され、いつでも続きから遊べます
      2. クエストを受注する
        クエスト名・サイズ・期限を入力して登録します
      3. 達成報告でExpを獲得
        積み上げることでレベルアップしていきます
      4. おすすめクエストを活用
        今やるべき行動を自動で提案してくれます
      5. データを守る
        バックアップ・復元で安心して使えます

      クエストサイズについて

      • 小クエスト：すぐ終わる行動向け（1〜3日 / 10Exp）
      • 中クエスト：数日かける挑戦向け（4〜7日 / 50Exp）
      • 大クエスト：長期で挑む目標向け（8日以上 / 100Exp）

      迷ったら、まずは小クエストから始めよう！

      カテゴリについて

      • カテゴリを付けると、クエストを種類ごとに整理できます
      • あとから「カテゴリ管理」からまとめて追加・変更もできます
      • 一覧ではカテゴリごとに絞り込み表示ができます

      勉強・仕事・生活 などで分けるのがおすすめ！

      データ管理について

      • ログイン：名前ごとにデータを保存
      • バックアップ：データをファイルとして保存
      • 復元：保存したデータを読み込み

      万が一に備えてバックアップを取っておこう！
